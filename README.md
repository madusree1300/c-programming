# DAY 1 C Basics

A collection of beginner-friendly C programs covering fundamental data types, string handling, conditional logic (`if-else` statements), and loops (`for` loops).

## 📂 Programs Included

### Data Types & Strings
* **`float program`** — Demonstrates declaring, reading, and displaying floating-point numbers.
* **`string program`** — Shows basic string input and output handling in C.
* **`string program highlight`** — Illustrates formatted or highlighted string manipulation and display.


# DAY 2 conditional statements and loops

### Conditional Statements (`if-else`)
* **`if statement`** — Introduces basic decision-making using simple `if` conditions.
* **`equal and not equal`** — Compares two values to check for equality (`==`) or inequality (`!=`).
* **`positive or negative or zero`** — Determines whether a given number is positive, negative, or zero.
* **`greatest of two numbers`** — Finds the larger value between two input numbers.
* **`greatest of three numbers`** — Compares three numbers to determine the largest one.
* **`divisible by 3`** — Checks if a given integer is completely divisible by 3.
* **`odd or even`** — Identifies whether an integer is odd or even using the modulus (`%`) operator.
* **`leap year not a leap year`** — Evaluates whether a given year is a leap year based on standard calendar rules.
* **`hi -3,hello -5 ,hi and hello-3.5`** — A FizzBuzz-style program that prints `"hi"` for multiples of 3, `"hello"` for multiples of 5, and `"hi and hello"` for numbers divisible by both 3 and 5.

### Loops (`for` Loop)
* **`for loop`** — Demonstrates basic iteration and syntax of a `for` loop in C.
* **`to find factors`** — Finds and displays all factors of a given integer.
* **`to find long number factor`** — Calculates factors for larger numbers using appropriate data types (such as `long` or `long long`).
* **`multiplication table`** — Generates and prints the multiplication table for a given number.
* **`counting numbers`** — Counts numbers or digits sequentially using loop logic.
